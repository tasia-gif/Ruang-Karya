RUANG KARYA — Website versi 1.1

ISI PAKET
- index.html: website responsif.
- assets/logo-mark.png: logo ringkas untuk header dan favicon.
- assets/logo-full.png: logo lengkap untuk identitas brand.

MENCOBA DI LAPTOP
1. Ekstrak ZIP.
2. Buka folder ruang-karya.
3. Klik dua kali index.html. Pastikan folder assets tetap berada di samping index.html.

MENERBITKAN GRATIS DENGAN GITHUB PAGES
1. Dengan bantuan orang tua/wali bila diperlukan, buat akun di https://github.com/.
2. Buat repository baru bernama ruang-karya dan pilih Public.
3. Unggah index.html DAN folder assets (beserta kedua file logo) ke halaman utama repository.
4. Buka Settings > Pages.
5. Pada Build and deployment, pilih Deploy from a branch.
6. Pilih branch main dan folder /(root), lalu Save.
7. Setelah proses selesai, situs akan tersedia pada alamat:
   https://NAMA-AKUN.github.io/ruang-karya/

PENTING
- Jangan mengunggah hanya index.html; folder assets juga diperlukan agar logo tampil.
- Pencarian dan filter kategori bekerja di browser.
- Sistem transaksi, pembayaran otomatis, akun pengguna, dan dashboard admin belum tersedia.
- Tambahkan konten orisinal dan informasi kontak yang memang kamu siapkan sendiri.
- Jangan mempublikasikan data pribadi sensitif.
- Untuk akun pembayaran atau monetisasi yang mensyaratkan usia dewasa, minta orang tua/wali mengelolanya.
- Pendapatan tidak dijamin; perlu konten bermanfaat, pengunjung, dan kepatuhan pada aturan platform.
